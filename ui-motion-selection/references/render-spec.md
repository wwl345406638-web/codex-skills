# 给 AI 的页面渲染输入

从已有设计变量、截图、字段字典、素材或接口取值。只补当前页面实际使用的字段。下面的数字供初稿试排；项目规范、真实字段和目标设备优先。设计参数写进规格或实现，页面只显示用户完成任务需要的信息。

## 哪些细节会改变渲染结果

| 设计对象 | 给渲染者的信息 | 可直接采用的表达示例 |
| --- | --- | --- |
| 构图与重排 | 目标视口、主次区域、边距、列宽上下限、断点行为 | 桌面宽 1440 px，主区与详情按 7∶5 分栏，间距 24 px；小于 960 px 改单栏。超长设备名允许换两行 |
| 字体与密度 | 字体栈、字号／行高、字重、控件间距、数字对齐 | 正文 14/22 px，标题 24/32 px、字重 600；读数使用等宽数字，单位紧跟数值；桌面表格行最小高 44 px |
| 色彩、材质与光照 | 语义色与前景底色组合、边界、透明度、光源方向、光效范围 | 告警文本 #9F2017 配浅底 #FDECEB，并显示“高温”；图片浮层可从 88% 不透明度和 8 px 背景模糊试起，背景复杂时改实底 |
| 图片与三维 | 真实素材或示意来源、主体方位、裁切焦点、景别、镜头、灯光与占比 | 设备三分之四前视图，主体占画面宽约 60%，主光从左上方入射，正面铭牌保持可辨。窄屏单独定裁切，标签放在轮廓外 |
| 业务字段与图表 | 样本身份、ID、值、单位、精度、观测时间、来源、统计口径、缺失含义 | 一行对应一台设备；温度留一位小数，时间与筛选共用项目时区。近一小时趋势显示时间轴与 °C 轴，断点可辨，阈值取已知配置 |
| 空间与图层 | 坐标系、单位、空间范围、点位和图层顺序、点选方式、镜头恢复 | 楼层示意图可用归一化坐标并声明原点在左上；模型位置用项目定义的局部坐标与单位；点、列表、详情共享 assetId |
| 运动和状态 | 触发者、目标、属性与起止值、时间或进度、曲线、打断规则、降级 | 点设备名时右栏 opacity 从 0.65 到 1，160 ms，cubic-bezier(0.2,0,0,1)；连续选择以最后一项为准；减少动态效果时立即显示 |

## 同一术语在不同交付物里的写法

例如在产品案例页表现“外壳打开，观察内部模块”，可以采用三维模型爆炸视图（3D Model Exploded View）。

- **交给出图模型**：画 16∶9 横幅的展开终帧，正交三分之四视角。左侧 38% 放标题，右侧沿同一拆解轴依次排列外壳、模块、底座。三层用相同光向、表面粗糙度和投影方向，标线指向对应部件。已有模型或产品图决定真实部件；概念件标为示意。需要分镜时再画相同镜头的收拢帧。
- **交给前端渲染器**：按模型提供的部件 ID 和本地坐标轴分组。令展开进度从 0 到 1，部件目标偏移以模型包围盒长度的比例表达，例如外壳 0.35、模块 0.15、底座 0。提供“展开／收拢”按钮，减弱动态时直接切换姿态。没有可分层模型时，改用有来源的分解图或两张标记为示意的静态帧。
